# Auto Deals Iraq - Current Stage

هذه النسخة تجمع الشغل الحالي:
- إصلاح VehDB وجلب قياسات الإطارات.
- الدخول إلى أسعار الإطارات من القياس.
- زر "اطلب الآن".
- كود طلب + QR + Barcode.
- العروض والخصومات.
- مراسلة الدعم داخل التطبيق بدون إظهار أي رقم.
- GPS.
- حساب المسافة.
- ترتيب المحلات حسب الأقرب.
- الاتجاهات عبر الخرائط.

مؤجل حالياً:
- الدفع الإلكتروني.
- ربط واتساب والرد الآلي.
